# Code-review methodology record

This historical note records the public source material that informed the code-review skill. It is not a runtime instruction file; the current operating boundary lives in `skills/code-review/SKILL.md`.

The method combines evidence-first review priorities with test-driven verification guidance for behavior changes:

- Takuto Wada, *AI時代のTDD / TDD in AI Era 202604 Edition*: https://speakerdeck.com/twada/tdd-in-ai-era-202604-edition
- Takuto Wada, *自動テスト実行結果の目的を整理する / Organizing objectives of automated test results*: https://speakerdeck.com/twada/organizing-objectives-of-automated-test-results

The skill intentionally keeps these references out of the default runtime path so that provenance does not expand the instructions loaded for every review.
