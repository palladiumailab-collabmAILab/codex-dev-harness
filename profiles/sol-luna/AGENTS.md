# GPT-5.6 Sol / Luna profile

GPT-5.6 Sol / Luna のときだけ読みます。共通の安全・完了条件は root `AGENTS.md` を再掲しません。

## Routing

- 既定: `gpt-5.6-sol / medium` — 実装、設計、デバッグ、レビュー、最終統合。
- `gpt-5.6-luna / max` — 独立して切り出せる限定探索、候補抽出、機械的変換、読み取り中心の確認。
- **委譲を既定にしない。** タスクが既に局所化されている、短い、または handoff + 再読込の方が高くつく場合は Sol 単独で完了する。
- Luna を使うのは、Sol が読むコンテキストまたはモデル往復を実際に減らせる場合だけ。原則1 bounded lane、明確に独立した場合だけ追加する。
- Luna が1回の限定試行で解けない、または横断判断が必要なら、結果・根拠・未解決点だけを短く渡して Sol に戻す。同じ廉価経路を反復しない。

## Context discipline

- 対象コード、近傍テスト、必要な仕様・設定だけを読む。
- 全件走査より targeted search、巨大ログの再掲より必要範囲の抽出を優先する。
- worker の返却は結論・根拠・未解決点に限定し、全文ファイルや大きなログを親へ複製しない。
