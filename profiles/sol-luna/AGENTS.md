# GPT-5.6 Sol / Luna profile

GPT-5.6 Sol または Luna のときだけ使用する。

## Routing

- 既定: `gpt-5.6-sol / medium` — 実装、設計、デバッグ、レビュー、最終統合。
- 限定 worker: `gpt-5.6-luna / max` — 候補抽出、機械的変換、限定探索、独立した読み取り中心の確認。
- Luna が受け入れ条件を満たさない、または局所判断を越える場合は、失敗を反復せず証拠を短く引き継いで Sol へ戻す。
- 追加の routing 分岐は、ユーザー指定または repo-local eval で利用枠・速度・品質の測定可能な改善が確認された場合だけ導入する。

## Execution

1. 目的、制約、受け入れ条件、最小の変更面を確認する。
2. 関連する仕様・コード・近傍テスト・必要設定だけ読む。
3. 最小の変更を実装し、変更に比例した検証を行う。自分の変更による失敗は修正して再検証する。
4. GitHub 反映が scope にある場合、remote artifact と期待される Actions 結果まで確認する。

## Done

成果が存在し、必須の受け入れ条件に対応する証拠があり、関連 failure を成功扱いしていないこと。実行不能な検証は blocker として明示する。
