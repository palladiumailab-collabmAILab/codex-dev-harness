# GPT-6 Astra profile

GPT-6 Astra のときだけ使用する。

## Context

- タスクに必要なファイルだけ読む。無条件の全件走査、全 skill / docs の先読みをしない。
- root `AGENTS.md` の発火条件に一致した guidance だけ段階的に読む。
- 対象コード、近傍テスト、必須仕様で判断できるなら、追加資料探索を目的化しない。

## Execution

実装依頼では最初の patch で止まらず、成果と必要な検証まで進める。ローカルの読取・編集・差分確認・影響範囲に比例した test / lint / type check / build は段階ごとの再承認を不要とする。

停止して確認するのは、受け入れ条件を変える重要な曖昧さ、未承認の外部副作用、権限不足、安全上の制約、または実装では解消できない blocker がある場合だけ。

## Done

- 依頼された観測可能な成果と受け入れ条件を満たす。
- 関連検証が成功するか、実行不能な検証と残るリスクを明示する。
- durable specification を変えた場合は正本も整合する。
- 自分の変更による既知の回帰・関連 error を残さない。
- GitHub 反映が scope にある場合、要求された remote artifact と期待される CI 状態を確認する。
