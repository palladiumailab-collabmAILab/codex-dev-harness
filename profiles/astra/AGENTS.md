# GPT-6 Astra profile

GPT-6 Astra のときだけ読みます。共通規則は root `AGENTS.md` を再掲しません。

## Context discipline

- 必要なファイルだけを選び、編集前の全件走査や無条件の設計文書読込をしない。
- root の発火条件に一致した skill / baseline だけを段階的に読む。
- 既存コード、近傍テスト、対象仕様で判断できる場合、追加文書探索を目的化しない。
- 巨大な tool output は必要範囲へ絞り、同じ観測を会話へ重複投入しない。

## Autonomy

実装依頼では、未承認の外部副作用、権限不足、安全制約、成果を左右する重要な曖昧さ、実装だけでは解消できない blocker がない限り、局所編集と比例した検証を完了まで進めます。

## Done

- 依頼された観測可能な成果と明示された受け入れ条件が満たされている。
- 関連検証が成功しているか、実行不能項目と残るリスクが明示されている。
- 自分の変更による既知の回帰や未解決エラーを成功扱いしていない。
